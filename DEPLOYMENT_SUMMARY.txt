⚡ QUICK START - CLOUD DEPLOYMENT:
═══════════════════════════════════════════════════════════════════

Phase 1: Push to GitHub (10 mins)
──────────────────────────────────
cd C:\Users\Petpooja-607\Desktop\pkt
git init
git add .
git commit -m "Initial commit"
# Create repo on GitHub: https://github.com/new
git remote add origin https://github.com/YOUR_USERNAME/petpooja-exam-dashboard.git
git push -u origin main

Phase 2: Deploy Backend to Railway (10 mins)
─────────────────────────────────────────────
1. Go to https://railway.app/
2. Sign in with GitHub
3. New Project → Deploy from GitHub
4. Select your repo
5. Set Root Directory: backend
6. Add environment variables (META_API_KEY, etc.)
7. Generate domain → SAVE URL!

Phase 3: Deploy Frontend to Vercel (10 mins)
─────────────────────────────────────────────
1. Go to https://vercel.com/
2. Sign in with GitHub
3. Import your repo
4. Set Root Directory: frontend
5. Add env variable: REACT_APP_API_URL=YOUR_RAILWAY_URL
6. Deploy → DONE!

Phase 4: Update CORS (5 mins)
──────────────────────────────
Edit backend/main.py CORS to include Vercel URL
git push → Auto-deploys!
