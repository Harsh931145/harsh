## Alternative Methods

### Method 2: Drag and Drop
```
1. Save screenshot to desktop
2. Drag file to search box
3. See blue dashed border
4. Drop!
5. Click "Get Answer"
```

### Method 3: Traditional Browse
```
1. Click 📷 camera icon
2. Browse to file
3. Select and open
4. Click "Get Answer"
```

## Keyboard Shortcuts

| Action | Shortcut |
|--------|----------|
| Windows Snipping Tool | `Win + Shift + S` |
| Full Screenshot | `Print Screen` |
| Paste Image | `Ctrl + V` |
| Submit Question | `Enter` (in search box) |
| Remove Image | Click `X` on preview |

## Pro Tips 💡

✅ **Fastest**: Win+Shift+S → Ctrl+V → Enter  
✅ **No saving required** - paste directly from clipboard  
✅ **Multiple attempts** - remove image and paste a different one  
✅ **Works with any image** - even from web pages (right-click → Copy image → Ctrl+V)
