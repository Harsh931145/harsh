# Petpooja Exam Dashboard - Quick User Guide

## 🚀 Getting Started (For Users)

### Step 1: Open the Dashboard
1. Open your web browser (Chrome, Edge, or Firefox)
2. Go to: **http://localhost:3000** (or the URL provided by admin)
3. You'll see "Exam Preparation Assistant"

### Step 2: First Time? Upload Study Materials (Admin Only)
1. Click **"📚 Manage Documents"**
2. Click **"Upload PDF"** button
3. Select Petpooja PDFs:
   - POS manual
   - Dashboard guide
   - Payroll/Attendo docs
   - Finance docs
4. Wait 5-10 seconds per file
5. Done! Documents are now searchable

---

## 📝 How to Ask MCQ Questions

### Method 1: Screenshot (RECOMMENDED)

1. **Take Screenshot of MCQ Question**
   - Windows: Press `Win + Shift + S`
   - Select the question area
   - Make sure you capture:
     ✅ Complete question
     ✅ All options (A, B, C, D)
     ✅ The BOLD answer is visible

2. **Paste into Dashboard**
   - Click in the search box
   - Press `Ctrl + V` to paste
   - You'll see the image appear

3. **Add Context (Optional)**
   - Type: "This is about POS billing"
   - Or just leave it blank

4. **Get Answer**
   - Click **"Get Answer"** button
   - Wait 3-5 seconds
   - See the answer!

### Method 2: Type Question

1. Type or paste your question in the search box
2. Click **"Get Answer"**
3. Wait for response

### What You'll See:

```
Answer: B) Split Bill

Reasoning: The "Split Bill" feature in Petpooja POS is specifically 
designed for dividing a single bill into multiple parts. This directly 
matches the question about splitting bills. Other options serve 
different purposes.

Keywords: POS, split, billing, divide
Confidence: 95%
Sources: petpooja_pos_manual.pdf
```

### What It Means:

- **Answer**: The correct option (usually the BOLD one from screenshot)
- **Reasoning**: Why this answer is correct
- **Keywords**: Important terms identified
- **Confidence**: How sure the AI is (90%+ is very good)
- **Sources**: Which PDFs were used

## ❓ Common Questions

### Q: Why is confidence low (<70%)?
**A:** Upload more study materials about that topic. The AI needs reference documents.

### Q: Can I paste multiple screenshots?
**A:** One at a time. Ask first question, then ask next one.

### Q: Does it work with images from phone?
**A:** Yes! Take photo of screen, save it, then drag-drop into search box.

### Q: What if the answer is wrong?
**A:** 
1. Check if study materials cover that topic
2. Upload more comprehensive PDFs
3. Read the reasoning to understand AI's logic
4. Cross-verify with official documentation

### Q: Can I use it for practice tests?
**A:** Yes! Perfect for:
- Practice MCQs
- Quick revision
- Understanding concepts
- Exam preparation

## 🛠️ Troubleshooting

### Problem: Can't access dashboard
**Solution:** 
- Check if backend and frontend are running
- Verify the URL (http://localhost:3000)
- Ask admin to check services

### Problem: "No relevant information found"
**Solution:**
- Admin needs to upload Petpooja documentation PDFs
- Make sure PDFs are about the topic you're asking

### Problem: Can't paste screenshot
**Solution:**
- Try clicking the 📷 image icon instead
- Browse and select saved screenshot file
- Or drag-drop the image file

### Problem: Answer takes too long
**Solution:**
- Wait 5-10 seconds (normal)
- Check internet connection
- Reload page and try again
