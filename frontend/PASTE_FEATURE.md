# 📸 Screenshot Paste Feature

## How to Use Screenshots

The search box now supports **3 easy ways** to add screenshots:

### Method 1: **Paste with Ctrl+V** (Easiest!) ⌨️

1. Take a screenshot using:
   - **Windows Snipping Tool** (Win+Shift+S)
   - **Print Screen** button
   - Any screenshot tool
2. Click inside the search box
3. Press **Ctrl+V** to paste
4. Your screenshot appears instantly!

### Method 2: **Drag and Drop** 🖱️

1. Take a screenshot and save it
2. Drag the image file over the search box
3. Drop it when you see the blue border
4. Done!

### Method 3: **Browse Files** 📁

1. Click the 📷 camera icon in the search box
2. Select your screenshot file
3. Click Open

## Features

✅ **Direct Paste** - No need to save screenshots first  
✅ **Drag & Drop** - Just drag images onto the search box  
✅ **File Browser** - Traditional file selection still works  
✅ **Preview** - See your image before submitting  
✅ **Remove** - Click X to remove and try again  

## Tips

💡 **Best Practice**: Use Windows Snipping Tool (Win+Shift+S) → Ctrl+V for fastest workflow

💡 **Works with**: PNG, JPG, GIF, WebP and other image formats

💡 **Multiple Screenshots**: Remove the first one, then paste another

## Example Workflow

1. See a question in your textbook
2. Press **Win+Shift+S** to capture it
3. Click in the search box
4. Press **Ctrl+V**
5. Click "Get Answer"
6. Done! ✅
